# Migrate legacy folder-Categories to flat Categories

Android persists flat Categories while iOS and the retired Linux client persisted Categories as special folder Phrase records, and backups may contain both models. Wingmate runs an idempotent shared migration at startup and before restoring legacy backup payloads: it writes an internal recovery snapshot, converts folder-Phrases to Categories with the same IDs, preserves Phrase membership, then discards folder-only visual, audio, and link metadata after verification. The migration is membership-preserving rather than literally lossless and aborts on ID ambiguity or cycles rather than guessing. Colliding Category names keep their old path (for example `School / People`) with suffixes for remaining collisions, and duplicates are never merged automatically.

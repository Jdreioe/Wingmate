# Model rich Page content as typed elements

Wingmate models rich Page content such as Phrase collections, Page navigation, and Action strips as typed Page elements in a Wingmate-specific OBF board extension. Each element has stable identity, grid placement, and typed configuration; unknown element payloads survive round trips and appear as unsupported placeholders in editing rather than disappearing. Standard OBF Buttons remain unchanged. A Phrase collection projects each live Phrase into a standard runtime OBF Button, with generated OBF Image and Sound records where applicable, inside its layout region. Page navigation renders live Page links as chips, and an Action strip arranges ordinary editable OBF Buttons whose actions invoke system-owned effects. Representing these rich containers as special Buttons would blur layout, editing, and activation semantics. The Typing Screen persists one shared layout and its Action-strip Buttons while projecting its Pages and Phrase Buttons from authoritative Phrase, Category, and History repositories. Generated projection data is never persisted or duplicated in Complete Backup, and the Typing Screen is excluded from normal vocabulary-package export.

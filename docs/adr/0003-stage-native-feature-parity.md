# Stage native feature parity

Wingmate may test a feature on one native client before implementing it elsewhere, but a released shared feature must work on Android and iOS or document a deliberate platform exception. While a replacement desktop client is being built, desktop consumes released shared behavior without becoming a release gate. Once desktop is listed as supported, shared features that apply to desktop must also work there or document a deliberate platform exception. Hardware-specific features may remain native when they use a platform adapter and do not complicate the shared communication model.

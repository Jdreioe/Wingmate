# Use the Typing Screen as an input surface

Wingmate presents the Typing Screen as a lower input surface that is mutually exclusive with the system keyboard, following the composer-and-picker relationship used by messaging apps. A compact Phrase row remains available while the Typing Screen is closed; opening it replaces that preview with the full shared Page layout, and `+` switches directly between the Typing Screen and system keyboard. This avoids a modal overlay and preserves one Message bar and live Phrase vocabulary across both presentations.

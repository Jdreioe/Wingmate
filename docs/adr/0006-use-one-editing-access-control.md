# Use one Editing access control

When enabled, Editing access protects all vocabulary changes in Typing and Screens without blocking communication or ordinary voice and access preferences. It locks when the app leaves the foreground or after ten minutes without an editing action, preserves unsaved edits, and requires the code before further changes. A Screen lock only freezes one Screen and relies on Editing access when configured; it has no separate PIN, biometric prompt, identity, or permission meaning.
